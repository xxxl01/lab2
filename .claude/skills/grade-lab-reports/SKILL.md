# 批改图类实验作业

适用：仓库根目录下每人一个 `<学号>-<姓名>` 文件夹，里面有报告 docx（或 doc）；成绩记录到 JSON。

## 1. 先做的准备
1. 读题目文档（含其中的图片），把题目要求、每题标准答案要点写下来。
2. 看教师给的参考 JSON，沿用其字段格式：`姓名 / 学号 / 分数 / 评语`。
3. 和教师确认评分口径（本次用过：完成度 60、正确性 30、报告 10；多数 60–100；态度差可不及格；抄袭封顶 70）。每题分值可调，见 `scripts/build_json.py`。
4. 记下题目文档自带的图（模板图）的 md5 前 8 位，设置环境变量 `TPL_HASHES=a,b,c` 以便在提取/查重时排除。

## 2. 提取图片（每批约 20 人）
`python3 -I scripts/extract.py <仓库根> <工作目录> <学号...>` → 每人一张 `sheet.png`（按题序排列）。
- 报告图片需逐张**亲眼看**，不能只看文字；报告里的图是否按题号对应，要核对。
- 只交了平台导出的 .doc 的人，图可能 base64 嵌在文件里，用 `scripts/extract_b64.py` 提取（文件大小明显大于其他人的 .doc 就是线索）。
- 平台自动生成的 .doc（体积全班几乎一致、无图）不是报告，不用批。

## 3. 全班查重（每批都要全局重跑）
`python3 -I scripts/similarity.py <各批工作目录...>`
- 脚本输出只是线索：同样的 Visio 窗口截图会误报；手机重拍同一张图会漏。**必须并排看图确认**。
- 分类记录：部分相同（1–2 张）、绝大部分相同（≥3 张）、多人拼合（一人的图来自多人）。
- 多数情况分不出谁抄谁（只有拼合者、或图的来源明显的才能判断），默认涉及的人一起封顶；教师可指定只压抄的一方。
- 题目附录里的示例图、教材原图被直接贴上的，不算原创，按缺该题处理。

## 4. 打分
- 逐人逐题记 (完成度, 正确性)，再记报告分、评语。评语写具体问题（如“第3题只重画了数据流图，没转成结构图”）。
- 教师先问“有没有区分度”时，给出分布并提出调整方案，不要自己改标准。
- 数据流图转结构图类题：判断是否按输入/变换/输出三部分分解，是否带数据流标注；只重画原图 = 基本未完成。
- 手机拍屏、非指定工具（如在线绘图）只在评语中提醒，轻扣分。

## 5. 生成 JSON
把打分写成 scores.json 后运行 `python3 -I scripts/build_json.py scores.json 成绩.json`：
自动累加总分、校验分值上限、处理抄袭封顶，并保留 `封顶前分数` 与逐题 `明细` 供教师核对。
每批完成后提交并推送到指定分支；全部完成后向教师汇报：分布、不及格原因、抄袭分组、需要教师确认的事项。

## 注意
- 先核对仓库里有无无文件夹的缺交者，再核对是否全员覆盖（对比学号清单）。
- 不要把某次作业的具体评语或分数当模板；每次按当次题目重新制定标准。
